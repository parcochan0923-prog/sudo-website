從散亂WhatsApp對話自動同步到Excel

一人網店如何用 AI 自動整理 WhatsApp 訂單，取代人手翻對話紀錄再填 Excel 的噩夢。

❌ 系統上線前 — 人手對照 WhatsApp 再填 Excel

經營網上玩具店，主要透過 WhatsApp 接單。每日收幾十條訊息——客人問價、落單、確認付款、追貨——全部混在同一個 chat 入面。

原本嘅流程：

  1. 打開 WhatsApp，逐條訊息翻閱
  2. 人手對照邊個落咗單、買咗乜、俾咗錢未
  3. 再手動逐筆填入 Excel

最痛嘅位：

  • 漏單 — 訊息多、節奏快，忙起嚟容易漏掉已落單但未記錄嘅客
  • 時間黑洞 — 每週花約 20 小時純粹做「翻紀錄 + 填表」嘅重複工作
  • 單人經營嘅風險 — 冇人 backup，一忙就亂，一亂就漏

對一個人嘅網店嚟講，20 小時幾乎係一個 part-time。而呢 20 小時做嘅嘢，本質上只係「搬資料」。

🔧 方案 — WhatsApp Deal Scanner

一個自動化 pipeline，每晚固定時間跑：

  1. 同步 WhatsApp 訊息 — 透過 wacli 將 WhatsApp 對話記錄同步到本地數據庫
  2. AI 掃描已成交訂單 — 辨識包含「收到」+「thanks」嘅確認訊息，鎖定已成交嘅對話
  3. AI 提取訂單細節 — 用 LLM 從對話中提取：產品名、數量、單價、總金額、付款方式
  4. 自動寫入 Google Sheet — 結構化資料直接 append 到試算表，冇人手介入

技術棧：

wacli — WhatsApp 訊息同步 Python + SQLite + Regex GLM-5 Turbo（LLM） Google Sheets API OpenClaw Cron — 定時觸發

💡 點解咁做？

點解唔直接用 Excel 優化？ Excel 本身冇問題，問題係入 data 嗰步——WhatsApp 嘅對話格式唔固定，人手閱讀再轉寫先係 bottleneck。

點解唔買現成 SaaS？ 市面上嘅 order management system 多數為多人大團隊設計，overkill 得滯。Google Sheet 係最無阻力嘅 output——開即睇，唔使登入。

點解用 AI 提取而唔係純 rule？ WhatsApp 對話冇固定格式。Regex 可以捉到「$150」呢啲 pattern，但要理解「兩盒 A + 三本 B 總數幾多」，AI 準確度同彈性好太多。

導入阻力極低： 冇改變接單方式、冇要客人做任何新嘢、冇新系統要學、每晚自動跑唔使手動觸發。

  • 冇再出現「記得收咗錢但搵唔返紀錄」嘅情況

對一人經營嘅意義：每週回收 14 小時，唔係 efficiency gain —— 係生存空間。嗰啲時間可以做返真正需要人嘅嘢：回覆客人、搵貨、處理物流、諗下點樣拓展業務。

⚠️ 挑戰同克服方式

  • WhatsApp 連線不穩定 — wacli sync 偶爾斷線，需要自動重連機制同 timeout 保護
  • 對話格式唔固定 — 初期純 regex 提取準確度唔夠，改用 LLM 後大幅改善，但仍需要定期覆核
  • 避免重複記錄 — 同一筆成交唔可以入兩次，需要 dedup 邏輯（用訂單 ID + timestamp）

🚀 未來發展

  • 接埋 POS 系統，令 WhatsApp 訂單直接入庫存
  • 自動生成每日/每週銷售摘要 report
